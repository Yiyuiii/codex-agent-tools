日期：2026-07-30

本机官方插件升级通过；等待后台宿主进程真正退出并重开后的真实宿主门禁。

## 发布目的

`0.1.1-beta.0` 修复官方插件在真实 Codex App 中无法启动相对 stdio runtime 的
问题。0.1.0 的 `.mcp.json` 声明了相对脚本参数，却没有声明工作目录；官方 CLI
因此显示 `cwd: -`。完整 App 重启后的新任务仍无法发现插件工具。

官方内置 Sites 本地 stdio 插件使用 `cwd: "."`，CLI 会将其解析到版本化插件
缓存根目录。本候选采用相同启动合同，并把原来由验收客户端隐式补齐的工作目录变成
manifest 必须显式提供、所有发布门禁必须验证的字段。

## 改动范围

- 插件 `.mcp.json` 增加 `cwd: "."`；
- artifact 测试和 release smoke 精确要求该字段；
- 隔离官方插件验收与公共 npm 消费者验收从已安装 manifest 读取 `cwd`，要求精确
  为 `"."`，再相对已安装插件根目录解析；测试不再无条件替宿主指定插件根目录；
- package、lock、runtime 和插件 manifest 统一升级到 `0.1.1-beta.0`；
- 更新隔离状态、真实宿主记录、README、发布清单和项目记忆；
- 不改变逻辑 LLM 注册表、模型路由、凭据来源、子进程策略、工具 schema、结果
  validator 或历史 evidence。
