# codex-agent-tools 0.1.0-beta.0 发布审阅

日期：2026-07-29

状态：本地候选门禁已通过；公开仓库、独立复审和 npm 首包 bootstrap 待完成。

## 发布目的

`0.1.0-beta.0` 是 npm 包名首次注册用的 bootstrap prerelease。包存在后才能在
npm 配置 GitHub Actions Trusted Publisher；后续 `0.1.0-beta.1` 必须由
GitHub OIDC 发布，并从公共 registry 完成隔离消费者验收，稳定版不得直接复用
beta.0 的手工发布路径。

## 改动范围

- `8f46d81` 增加 Node 20/22/24 CI、tag release workflow、npm/GitHub 身份
  门禁、稳定版证据门禁，并升级 MCP SDK 到 1.30.0；
- 能力依赖指纹从整个 lockfile 收窄为 Pi/direct 的 `execa + zod` 闭包与
  Kimi/ACP 额外的 `@agentclientprotocol/sdk` 闭包，八项 evidence 与 manifest

  临时 Codex home 官方插件生命周期、进程与资格锁清零；
- package、runtime 与插件 manifest 统一为 `0.1.0-beta.0`。

- 本机 npm 当前未认证；首包需要一次 npm web login。认证未完成时停止在发布前，

  使用新的 beta 序号修复，不复用已发布版本。
- GitHub tag 必须可从 `next` 到达；稳定 tag 必须可从 `main` 到达并包含
  `.release-validation/v0.1.0.md`。
