## 发布目的

Publishing / GitHub OIDC 路径，并从公共 registry 对精确版本执行消费者视角的
CLI、doctor、MCP 和官方插件生命周期验收。它不能复用 `0.1.0-beta.0` 的手工
bootstrap 发布路径，也不能在首包和 Trusted Publisher 建立前打标签。
