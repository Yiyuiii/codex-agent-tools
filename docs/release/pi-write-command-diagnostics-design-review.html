  • ordinal 6 的 18 个 Pi bash 生命周期全部为 error，规定写入命令为 exact / error。
  • ordinal 1 的 5 个 Pi bash 生命周期同样全部为 error，规定写入也是 exact / error。
  • 两项最终结果文件均可安全读取，内容与哈希正确，证明“最终制品正确”不能替代 “规定 bash 成功”的证据。

离线根因：Windows shell 发现环境缺口

离线复现确认，隔离子环境没有向 Pi 0.80.10 传递 ProgramFiles 与 ProgramFiles(x86)。Pi 的 getShellConfig() 因而无法从标准 Git 安装目录定位 Git Bash，并回退到失败的 PATH 搜索。该缺口与 Ark 额度状态相互独立。

修复 离线证据 安全边界
2a815c7 在基础环境白名单加入 ProgramFiles、ProgramFiles(x86) 生产 environment builder 下，Pi resolver 解析到本机 Git Bash；与生产相同的 Node 写入命令 exit 0，并生成精确预期文件 不加入 ProgramW6432；不继承代理或额外凭据；不固定宿主路径； 不修改非 Windows shell 选择逻辑
